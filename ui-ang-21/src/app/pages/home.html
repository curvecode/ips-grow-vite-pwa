Understanding Writable Signals

  • signal(value): Creates a writable signal with an initial value
  • signal(): In template, reads the current value
  • .set(value): Replaces the entire value
  • .update(fn): Updates based on current value
  • computed(): Creates derived values that auto-update
  • WritableSignal<T>: Type for signals with get/set capabilities
  • input(): Signal input from parent component
  • output(): Emit events from child to parent
